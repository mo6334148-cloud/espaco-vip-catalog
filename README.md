# Espaço VIP Catalog

Crie um site mobile-first para um salão de beleza chamado:

ESPAÇO VIP

Logo abaixo do nome, mostrar em tamanho menor:

"Salão de beleza em SP"

Quero que o site tenha como principal referência a imagem anexada, especialmente o estilo de catálogo mostrado nela.

A ideia é criar um catálogo de serviços de salão de beleza com visual moderno, elegante e simples, onde cada serviço aparece em uma lista com:
- foto do serviço
- nome
- descrição
- preço
- botão "+" para adicionar/agendar

O site deve funcionar muito bem no celular e ter aparência semelhante a um catálogo de serviços de aplicativo.

==================================================
IDENTIDADE VISUAL
==================================================

Criar um visual sofisticado para o Espaço VIP.

Cores:
- fundo preto/grafite bem escuro
- textos brancos
- textos secundários em cinza claro
- detalhes em rosa/magenta
- botões e elementos de destaque em rosa/magenta
- pequenos detalhes em branco

Usar bordas arredondadas e imagens quadradas com cantos arredondados.

A interface deve ser limpa, moderna e feminina, sem exagerar nos elementos.
